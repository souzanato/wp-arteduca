Crie perfis personalizados para controlar quais menus do wp-admin cada usuário pode acessar.

== Descrição ==

O Bebelume Roles permite criar perfis de acesso customizados para o painel administrativo do WordPress. Com ele você pode:

* Criar perfis com título e descrição
* Selecionar quais menus e submenus do wp-admin cada perfil pode acessar
* Atribuir perfis a usuários individuais
* Bloquear acesso direto por URL a páginas não permitidas

== Instalação ==

1. Faça upload da pasta `bebelume-roles` para `/wp-content/plugins/`
2. Ative o plugin em Plugins > Plugins Instalados
3. Acesse **Bebelume Roles** no menu lateral do wp-admin
4. Crie seu primeiro perfil selecionando os menus permitidos
5. Vá até Usuários > edite um usuário e atribua o perfil Bebelume

== Como Usar ==

1. **Criar Perfil**: Vá em Bebelume Roles > Criar Perfil
2. **Configurar Menus**: Selecione os menus e submenus que o perfil pode acessar
3. **Atribuir a Usuários**: Edite o usuário desejado e selecione o perfil no campo "Perfil de Acesso"

**Nota**: Administradores nunca são filtrados - eles sempre têm acesso completo.
